# Вебпрактика

Учебный портал о PHP и веб-разработке. Курсовой проект по ОСВР.

Лукьянчук Владимир Алексеевич, группа **253-321**.

[Открыть сайт](https://vladimirlamospolytech.alwaysdata.net/coursework/)

## Что есть на сайте

- Материалы с поиском, фильтром по теме и разбивкой на страницы.
- Регистрация, вход и личный кабинет с публикацией своих статей.
- Комментарии к статьям с редактированием и удалением своих сообщений.
- Расчёт времени подготовки по выбранным материалам.
- Форма обратной связи с сохранением обращений в базе.

## Как устроен проект

PHP 8.4, SQLite, HTML, CSS и JavaScript. Используется собственный учебный backend-фреймворк по материалам третьего блока курса: MVC, фронт-контроллер, маршрутизатор, автозагрузка классов, Active Record и одно соединение PDO на запрос.

| Папка или файл | Назначение |
| --- | --- |
| `public/` | Точка входа и файлы оформления |
| `src/App/Core/` | Основа фреймворка |
| `src/App/Controllers/` | Обработка запросов |
| `src/App/Models/` | Работа с базой данных |
| `views/` | Шаблоны страниц |
| `database/` | Структура базы и учебные данные |
| `routes.php` | Маршруты сайта |

## Запуск

Нужен PHP с расширениями `pdo_sqlite` и `mbstring`. Из папки проекта:

```sh
php -S localhost:8000 -t public router.php
```

Открыть [localhost:8000](http://localhost:8000/). База `storage/course.sqlite` создаётся при первом обращении; в ней появятся восемь статей и примеры комментариев. Учебные авторы не имеют общедоступных паролей — для публикаций нужно зарегистрировать свой аккаунт.

На хостинге корневая папка сайта — `public/`. Каталог `storage/` должен быть доступен PHP для записи. При размещении в подпапке переменная окружения `APP_BASE_PATH` задаёт её префикс, например `/coursework`. Необязательная `COURSE_DB_PATH` задаёт другой путь к SQLite.
